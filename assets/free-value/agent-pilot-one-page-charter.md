# The one-page AI agent pilot charter

Free to use, copy and share. No signup. Draft v0.1 by Moring AI (moring.ai). Licence: CC BY 4.0 (proposed).

Many agent pilots end without a clear yes or no because nobody wrote down, before they started, what yes would look like. Fill in this page before any build starts. If a line cannot be filled in, the pilot is not ready to start.
